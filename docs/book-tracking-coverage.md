# Book Tracking Law Coverage

Status: verified implementation baseline (2026-07-21).

This matrix traces every numbered law in `docs/book-tracking-contract.md` to its implementation, API contract, automated coverage, and authenticated simulator evidence. The detailed run record is `docs/book-tracking-simulator-verification.md`.

## Status vocabulary

- **Planned — not verified**: implementation and tests still need to be completed and verified.
- **In progress — not verified**: work has started, but the law has not passed its required automated and simulator checks.
- **Implemented — automated verification pending**: code exists and has been reviewed, but required tests have not all passed.
- **Simulator verification pending**: required automated checks pass, but the mapped simulator evidence is incomplete.
- **Verified**: implementation, API behavior, automated tests, simulator evidence, and regression checks all pass.
