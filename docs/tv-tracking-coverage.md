# TV tracking coverage

Status: every law and acceptance case has automated tests; the native flows passed in the simulator (2026-10-26).

This matrix maps every numbered law in [the TV tracking contract](tv-tracking-contract.md) to the backend and iOS tests that pin it, and to the simulator flows that showed it in the real app.
The simulator run is recorded in [the simulator verification record](tv-tracking-simulator-verification.md).
The contract changed only where the user asked on 2026-10-26 and where TV-703 now follows the activity contract (its Review status); those changes are covered by the tests below, not yet by a simulator run.

Webhooks, imports, export, the hourly job, other time zones and PostgreSQL weren't run in the simulator; their laws rest on the backend tests.
